# Mihir Vaghela Portfolio

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Edit your email and social links in `index.html`.
4. Replace `assets/profile.jpg` whenever you want to change the profile photo.

Files:
- index.html
- style.css
- script.js
- assets/profile.jpg
